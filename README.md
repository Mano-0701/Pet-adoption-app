# Pet Adoption — TypeScript build

Quick steps to build the TypeScript source (`main.ts`) into `js/main.js`:

1. Install dev dependencies:

```powershell
npm install
```

2. Build once:

```powershell
npm run build
```

3. During development (watch mode):

```powershell
npm run watch
```

4. Ensure your HTML pages load the compiled script at `js/main.js`.
